# Markdown MCP developer documentation

Start here before changing application source. Executable source, package
metadata, schemas, and behavioral tests define behavior; these documents explain
ownership and invariants.

- [`workflow.md`](workflow.md) — application change and release workflow.
- [`architecture/`](architecture/index.md) — component boundaries and security
  invariants.
- [`types/`](types/index.md) — section-addressable internal and model-facing
  contracts.
- [`features/`](features/index.md) — released and planned feature contracts.

User setup and operation guidance is in [`../README.md`](../README.md). The
concise feature checklist is in [`../ROADMAP.md`](../ROADMAP.md), and released
changes are in [`../HISTORY.md`](../HISTORY.md).
