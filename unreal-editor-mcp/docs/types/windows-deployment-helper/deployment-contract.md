# Windows deployment contract

The selected directory must exist, contain at most 4,096 immediate entries, and contain exactly one immediate `.uproject` file. The descriptor is bounded to 1 MiB, must be a JSON object, and may contain only a string `EngineAssociation` of at most 128 characters for discovery purposes. The Engine input defaults to the trimmed `UE58` value. A valid configured value remains selected; otherwise registry discovery examines at most 256 Epic Launcher entries and 256 registered user builds. The Engine root must contain `Engine/Build/BatchFiles/RunUAT.bat`, and `Engine/Build/Build.version` must report integer major/minor fields of 5.8 or newer.

The helper always packages the fixed base descriptor and optionally packages the fixed `UnrealMCPGAS` descriptor with the base descriptor supplied as its UAT dependency. Each `BuildPlugin` call uses `-Rocket`, `-NoP4`, `-UTF8Output`, and `-TargetPlatforms=Win64`. It does not use `-Unversioned`, so the results are compatible with the selected Engine build rather than an arbitrary Unreal installation. All selected packages must build and pass package verification before installation begins.

Binary installation retains only the selected plugin's `Source/<PluginName>/<PluginName>.Build.cs` from its module source tree, because Unreal Build Tool still needs that module rule to consume a precompiled plugin. Each module rule is bounded to 64 KiB. The helper inserts `bUsePrecompiled = true` immediately before the one expected `PCHUsage` assignment and rejects a changed or ambiguous source rule instead of guessing. It removes C++ implementation and headers, every `.dSYM` bundle, and files ending in `.pdb`, `.ipdb`, `.iobj`, `.idb`, `.ilk`, `.obj`, `.pch`, `.map`, or `.debug`, case-insensitively. When the user enables PDB crash symbols, the filter retains only `.pdb` files directly under `Binaries/Win64` whose case-insensitive basenames match DLLs there; every deployed DLL must have a match. Packaged `Intermediate` precompiled manifests/import libraries remain. Each result must retain an installed descriptor, the precompiled module rule, and at least one direct Win64 DLL.

The exact install method is one of `project`, `engine_enabled`, or `engine_disabled`. Project destinations are `<Project>/Plugins/UnrealMCP` and, when selected, `<Project>/Plugins/UnrealMCPGAS`. The `.uproject` `Plugins` array is bounded to 4,096 references; matching names are case-insensitive and must be unique, and the helper adds or sets `Enabled: true` for every selected plugin through an atomic same-directory replacement. Indirect/reparse-point project descriptors reject.

Engine destinations are `<Engine>/Engine/Plugins/Marketplace/<PluginName>`. `engine_enabled` writes `EnabledByDefault: true` into every installed descriptor; `engine_disabled` writes `EnabledByDefault: false`. Project descriptor state is unchanged for both Engine methods.

Any existing selected directory requires one explicit replacement authorization. The helper captures selected-destination existence and the exact project descriptor before the build, then rejects if either changes before commit. All packages are copied, configured, and verified in sibling staging directories before existing installations are renamed. The selected plugin set is committed as one transaction; failure restores every prior directory and prevents partial base/companion installation. On success, temporary staging and backup directories are removed.

One launch definition owns the stable `unreal-editor` server name, `command`, and ordered `args`. `command` is the absolute Python executable that launched the helper. `args` begins with the absolute checkout `server.py` path and exact selected `.uproject` path, which is the default readonly configuration. The independent writable choice appends `--writable`. The independent lifecycle choice appends `--editor-lifecycle` and the resolved selected Engine's existing regular `Engine/Binaries/Win64/UnrealEditor.exe`; a missing, relative, or differently named executable rejects. When both are selected, writable precedes lifecycle in deterministic argument order.

After successful installation, the GUI renders that definition in two tabs. **LM Studio JSON** shows one complete `mcpServers.unreal-editor` object. **ChatGPT Codex STDIO** shows the server name, command, and each argument in separate readonly fields with independent copy actions; unused optional argument rows are empty and not copyable. Users manually add or merge the displayed values into their chosen host. Neither preview writes host configuration or contains the bridge token or generated project state.
