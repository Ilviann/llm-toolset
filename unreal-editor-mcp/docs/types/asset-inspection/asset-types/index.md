# Asset inspection type reviews

These pages define the accepted root properties and hierarchical selectors for the staged `asset_inspect` family set.

## Reviews

- [`actor-component-blueprint.md`](actor-component-blueprint.md) — standalone Actor Component Blueprint assets.
- [`game-instance-blueprint.md`](game-instance-blueprint.md) — process-local GameInstance lifecycle and logic assets.
- [`game-mode-blueprint.md`](game-mode-blueprint.md) — server-authoritative GameModeBase and match-state GameMode assets.
- [`game-state-blueprint.md`](game-state-blueprint.md) — replicated GameStateBase and match-state GameState assets.
- [`player-controller-blueprint.md`](player-controller-blueprint.md) — owning-player networking, possession, camera, input, and streaming behavior.
- [`player-state-blueprint.md`](player-state-blueprint.md) — globally replicated player identity, score, ping, and travel/reconnection state.
- [`animation-blueprint.md`](animation-blueprint.md) — animation lifecycle logic, pose graphs, layers, state machines, states, and transitions.
- [`interface-blueprint.md`](interface-blueprint.md) — Blueprint Interface identity, callable declarations, signatures, and semantic metadata.
- [`data-table.md`](data-table.md) — typed schema, table policies, row indexes, rows, and optional column projections.
- [`data-asset.md`](data-asset.md) — reflected instance or class-default data, Primary Asset identity, bundles, and pageable collection properties.
- [`widget-blueprint.md`](widget-blueprint.md) — base UMG class defaults, logic, hierarchy, layout, bindings, and named slots.
