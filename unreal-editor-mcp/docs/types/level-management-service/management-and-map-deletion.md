# Management and map-deletion contracts

`level_manage` is ledger-backed and accepts exactly `create` or `configure`. Both operations require the latest 40-hex `level_inspect {"mode":"current"}` snapshot and reject dirty or incomplete current-map state.

Blank creation uses an exact new mounted object path such as `/Game/Maps/Arena.Arena`, `source:{"kind":"blank"}`, explicit `world_partition`, `world_partition_streaming`, and `external_actors` booleans, and an explicit `open_after_create` choice. Streaming requires World Partition, and World Partition requires external actors. Template creation instead supplies one exact clean mounted `source.map_path`, inherits its package topology, and rejects creation options. Neither form accepts a `.umap` filename.

`settings` contains at most 16 unique assignments from the published World Settings allowlist. Values use the shared property codec. The list includes the compatible `DefaultGameMode` class override plus bounded world, physics, rendering, and scalar/struct settings; World Partition, external actors, streaming topology, arrays, maps, delegates, and arbitrary reflection are not editable setup fields.

`configure` targets only the exact current mounted map, requires one or more settings, saves it, and takes an explicit `reload_after_save` boolean. Results include exact changed-property read-back, effective creation facts, map ID/revision/snapshot, and per-package persistence for the root plus every bounded loaded external/build-data package. Creation that does not open the map unloads and reloads the clean new package without clearing transactions; creation that opens it verifies through `level_open`. A lost response must be reconciled through `operation_status`.

Map deletion reuses `asset_delete` and its latest exact `asset_references` snapshot. A World target must be inactive, clean, writable, and unreferenced. The service enumerates a bounded complete closure containing the map, separate build data, and on-disk external actor/object packages, rejects external registry or live-memory referencers and incomplete state, then passes the World to Unreal's public reference-aware asset deletion path. Success reports `map_deletion:true`, `package_closure_complete:true`, and per-package registry/storage absence. Deletion is non-Undoable and never force-deletes, rewrites referencers, fixes redirectors, or removes `.umap`/sidecar files directly. A `partial` or unknown outcome requires operation reconciliation and registry/storage inspection after restart.
